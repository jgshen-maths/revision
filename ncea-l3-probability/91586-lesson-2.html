TOOL 1

Discrete probability distributions

The idea
  • A discrete random variable \(X\) takes separate values (0, 1, 2, …). Its distribution lists every value with its probability.
  • The probabilities must add to 1. A missing one is 1 minus the rest.
  • Translate the words carefully: “at least 2” is \(X\ge2\); “more than 2” is \(X\ge3\); “fewer than 2” is \(X\le1\); “at most 2” is \(X\le2\).

TOOL 2

Expected value: the long-run average

The idea

\[E(X)=\sum x\,P(X=x)\] Multiply each value by its probability and add. \(E(X)\) is the average over many repeats. It does not have to be a possible value of \(X\).

TOOL 3

Expected counts: does the model match the data?

The idea

If a model is right, out of \(n\) observations we expect about \(n\times P(X=x)\) to have the value \(x\). Compare these expected counts with the observed counts.

A Poisson model has mean = variance. If the data's variance is much bigger than its mean, the events probably come in clusters and the Poisson model may not fit.

1 · Model vs data

Tool C · about 16 minutes

Technique

Is the model appropriate? The examiners want evidence from three places:

  1. Shape: compare the data's shape (peaks, skew, gaps) with the model's shape. A Poisson or normal model has one peak.
  2. Numbers: compare a model probability with the observed proportion, or an expected count with an observed count. Quote both numbers.
  3. Simulation: if observed counts fall outside the simulated band, the data are unlikely under the model.
  4. Context: do the model's features (fixed min or max, symmetry, independence) make sense for these people?

Poisson check: the mean and the variance should be about equal. For the lunch data, \(\bar x=3.26\) but the variance is much larger, which points to clustering.

Worked example

Weekly café lunches. 150 office workers recorded how many lunches they bought at the café in one week (0 to 7+). The mean is 3.26. Is \(\text{Po}(3.26)\) a good model?

  • The model expects \(150\times e^{-3.26}=150\times0.0384=5.8\) workers with 0 lunches, but 34 were observed, far above the simulated band.
  • The data have two peaks (0 and 5). A Poisson distribution has only one.
  • Context: many workers buy lunch every weekday (5), and others always bring lunch (0). Purchases are not independent random events at a constant rate.
“The Poisson model is not appropriate. It predicts about 6 workers buying no lunches, but 34 did, which is outside the simulated range. The data are bimodal at 0 and 5 because workers tend to have a habit (always or every weekday), so lunches are not independent events at a constant rate.”

2 · Conditions & effects

About 14 minutes

Technique

The conditions for each model, which you must write in context:

ModelConditions
Binomiala fixed number of trials \(n\); two outcomes; constant \(p\); independent trials
Poissonevents occur randomly and independently; at a constant average rate; one at a time (not simultaneously); counted in a fixed interval
Normalcontinuous, symmetric and unimodal; little probability given to impossible values
Triangular / uniforma known minimum and maximum (and mode); uniform only if every value is equally likely
  1. Name the condition in the words of the context.
  2. Judge it: is it reasonable here? Give a reason from the context.
  3. Effect (Excellence): if it fails, what goes wrong? For example, clustered arrivals make the variance larger than the mean, so the Poisson model underestimates both very quiet and very busy periods.

Careful: “two skiers cannot arrive at exactly the same instant” supports the Poisson condition. Stated as a criticism, it earns no credit.

Worked example

Ski-lift ticket booth. Skiers arrive at a booth at an average of 2.5 per minute, modelled by \(\text{Po}(2.5)\).

  • Independence: “Skiers arriving is assumed to be independent. This is unlikely, because families and school groups arrive together.”
  • Constant rate: “The rate of 2.5 per minute is unlikely to be constant. There will be a rush when the field opens and fewer arrivals later.”
  • Effect: “Because groups arrive together, the counts are more spread out than the model predicts. The model would underestimate \(P(X=0)=0.0821\) and \(P(X\ge5)=0.1088\), so the booth may be under-staffed at peak times.”

3 · Discrete RVs

Tool D · about 16 minutes

Technique
  1. Check that \(\sum p=1\). Find a missing \(p\) as 1 minus the rest.
  2. \(E(X)=\sum xp\), \(E(X^2)=\sum x^2p\), \(\text{Var}(X)=E(X^2)-[E(X)]^2\), \(\text{SD}=\sqrt{\text{Var}}\).
  3. Casio: MENU → STAT, List 1 = x, List 2 = P → F2 CALC → F6 SET: 1Var XList = List1, 1Var Freq = List2 → EXIT → F1 1VAR. Read \(\bar x=E(X)\) and \(\sigma_x=\text{SD}\). Use \(\sigma_x\), not \(s_x\).
  4. Linear change \(Y=aX+b\): \(E(Y)=aE(X)+b\), \(\text{SD}(Y)=|a|\,\text{SD}(X)\).
  5. Sum: \(E(X+Y)=E(X)+E(Y)\) always. \(\text{Var}(X+Y)=\text{Var}X+\text{Var}Y\) only if independent. Compare with the observed variance to judge independence.
Worked example

Late deliveries. \(X\) is the number of late deliveries a courier has in a day:

\(x\)01234
\(P\)0.30.350.20.10.05

\(E(X)=0.35+0.4+0.3+0.2=1.25\). \(E(X^2)=0.35+0.8+0.9+0.8=2.85\). \(\text{Var}=2.85-1.25^2=1.2875\), so \(\text{SD}=1.1347\).

Each late delivery costs the firm $40, plus a $10 daily admin fee: \(C=40X+10\). So \(E(C)=40(1.25)+10=\$60\) and \(\text{SD}(C)=40(1.1347)=\$45.39\). The $10 fee does not change the spread.

Theorem

Theorem 1. \(\text{Var}(aX+b)=a^2\text{Var}(X)\).

Theorem 2. If \(X\) and \(Y\) are independent, then \(\text{Var}(X+Y)=\text{Var}(X)+\text{Var}(Y)\).

What they say, with concrete examples:

  • Doubling all the prices doubles the SD, and the variance goes up 4 times. Adding a $10 fee changes nothing about the spread.
  • Coffees (Var 0.81) and muffins (Var 0.44): if they were independent, Var(total) = 1.25. The café observes 1.80, which is bigger, so students who buy more coffee tend to buy more muffins.
  • What it can do: test whether two variables are independent using only their variances.
Proofs (for interested readers)

1. Let \(\mu=E(X)\). Then \(E(aX+b)=a\mu+b\), so \[\text{Var}(aX+b)=E\big[(aX+b-a\mu-b)^2\big]=E\big[a^2(X-\mu)^2\big]=a^2\text{Var}(X).\]

2. Let \(\mu_X,\mu_Y\) be the means. Then \[\text{Var}(X+Y)=E\big[((X-\mu_X)+(Y-\mu_Y))^2\big]=\text{Var}X+\text{Var}Y+2E\big[(X-\mu_X)(Y-\mu_Y)\big].\] If they are independent, \(E[(X-\mu_X)(Y-\mu_Y)]=E[X-\mu_X]\,E[Y-\mu_Y]=0\times0=0\). If instead the observed variance is bigger, this cross term must be positive: large \(X\) goes with large \(Y\). ∎

4 · Writing for Excellence

About 8 minutes, then the mini-paper (printed).

Technique

91586 sentence frames. Fill each one with numbers and context.

Model choice: “A ___ model is appropriate because ___ (feature of the distribution) and in this context ___.”
Model vs data: “The model predicts ___, but ___ was observed. This is (inside / outside) the simulated range, so the model (is / is not) consistent with the data.”
Condition: “The ___ model assumes ___. Here this means ___, which is (reasonable / doubtful) because ___.”
Effect (Excellence): “If ___ does not hold, then ___, so the model would (under / over)-estimate ___.”
Interpret: “On average, ___ per ___. The SD of ___ shows that ___ typically varies by about ___ from this.”
Worked example

Merit or Excellence? Here are two answers to “Is \(\text{Po}(2.5)\) suitable for skier arrivals?”

Merit: “The Poisson model needs arrivals to be independent and at a constant rate. Skiers may arrive in groups.”

Excellence: “The Poisson model needs arrivals to be independent. This is doubtful because families and bus groups arrive together. As a result, arrival counts would be more variable than the model predicts, so it would underestimate \(P(X\ge5)=0.1088\), and the booth could be under-staffed at peak times.”

The difference: the Excellence answer gives the consequence, the direction, and a number.
