# Interactive Maths

GitHub Pages site. `index.html` is the course directory.

## Courses
- `y10-statistics-probability/revision.html`: NCEA Year 10 Statistics and Probability (interactive revision)
- `y10-statistics-probability/review-sheet.html`: printable review sheet for the same course

## Add a new course
1. Make a new folder, e.g. `y9-geometry/`, and put the course HTML in it.
2. In `index.html`, find the `COURSES` list and set that course's line to `ready:true` with `href:'y9-geometry/your-file.html'` (or add a new line).

## Publish
Settings → Pages → Deploy from a branch → `main` / `(root)`.
