Step 1: Closure, and Why We Needed New Numbers

In Chapter 1 you learned that a set is a collection and that $a \in S$ means “$a$ belongs to $S$”. Now we ask a new question: what happens when we calculate with members of a set?

1

An operation can “escape” the set

Let $\mathbb{Z}^+ = \{1,2,3,\ldots\}$ be the positive integers (the counting numbers). Both $8 \in \mathbb{Z}^+$ and $5 \in \mathbb{Z}^+$.

$8 + 5 = 13$. Is $13 \in \mathbb{Z}^+$? Yes, we stayed inside.

$5 - 8 = -3$. Is $-3 \in \mathbb{Z}^+$? No! The answer escaped from our set. In our counting-number world, that question had no answer.

2

What does “closed” mean?

A set $S$ is closed under an operation (like $+$, $-$, $\times$) if combining any two members of $S$ (they may be the same member twice) always gives an answer that is still in $S$.

In set language: “if $a \in S$ and $b \in S$, then $a + b \in S$.” Think of $S$ as an island: if every calculation lands on the island, the island is closed.

Proving vs disproving. To show a set is not closed, one counterexample is enough ($5-8$ above). To show it is closed, trying examples is not enough: we need a reason that works for all pairs.

3

Why do we care?

Guaranteed answers.
If a set is closed, every calculation has an answer in the same world. No surprises, no “impossible”.
Safe chains of steps.
You can do a long calculation, step after step, and trust that each intermediate result is still a legal number of your system.
It drives discovery.
When a set is not closed, mathematicians build a bigger set that fixes it. That is exactly how negative numbers were born.

5

The fix: build $\mathbb{Z}$

Add the number $0$ and the negative integers $\mathbb{Z}^- = \{\ldots,-3,-2,-1\}$ to $\mathbb{Z}^+$. The result is the set of integers:

$\mathbb{Z} = \mathbb{Z}^- \cup \{0\} \cup \mathbb{Z}^+ = \{\ldots,-3,-2,-1,0,1,2,3,\ldots\}$

  • The three pieces do not overlap (they are disjoint) and together make everything: a partition of $\mathbb{Z}$, just like a Venn diagram with three separate regions.
  • $\mathbb{Z}^+ \subset \mathbb{Z}$: the old world sits inside the new one (proper subset).
  • $\mathbb{Z}$ is closed under $+$, $-$ and $\times$. Subtraction now always works because $a - b = a + (-b)$, and $-b$ is also an integer.
  • $\mathbb{Z}$ is not closed under $\div$: $1 \div 2 \notin \mathbb{Z}$. That problem will lead us to fractions in a later chapter.

Step 2: The Integer Number Line, Order and Inequalities

Integers have a natural order. The number line makes that order visible: further right means bigger.

1

Opposites and comparing

Every integer $a$ has an opposite $-a$, the mirror image across $0$. They cancel: $a + (-a) = 0$. Also $-(-a) = a$.

We compare with $<$ (less than), $>$ (greater than), $\le$ (less than or equal), $\ge$ (greater than or equal).

Opposites: the opposite of A is , and A + (opposite of A) = 0.

2

Inequalities on a number line

  • Open circle ○: the end value is not included ($<$ or $>$).
  • Closed circle ●: the end value is included ($\le$ or $\ge$).
  • Shade toward the numbers that satisfy it. An arrow-end means “keeps going”.
  • Compound inequality $-2 \le x < 3$ reads “$x$ is at least $-2$ and less than $3$”.

Over the integers we can also list the solutions as a set: $\{x : x \in \mathbb{Z},\ -2 \le x < 3\} = \{-2,-1,0,1,2\}$.

Step 3: The Rules of Addition in $\mathbb{Z}$

Once a set is closed, we ask what rules the operation follows. These rules are what let us calculate cleverly.

Commutativity (order)

$a + b = b + a$

You may swap the order of two numbers being added.

Associativity (grouping)

$(a+b)+c = a+(b+c)$

You may choose which pair to add first. Brackets can move.

Identity

$a + 0 = a$

Zero does nothing when added.

Opposites (inverses)

$a + (-a) = 0$

Every integer has a partner that cancels it.

1

See commutativity: two routes, same destination

2

See associativity: move the brackets

3

Subtraction breaks the rules, so we glue the sign on

Subtraction is not commutative: $5 - 3 = 2$ but $3 - 5 = -2$.

Subtraction is not associative: $(10-5)-2 = 3$ but $10-(5-2) = 7$.

The rescue: subtracting is the same as adding the opposite, $a - b = a + (-b)$. After rewriting, every term is a signed number being added, so commutativity and associativity apply. The sign stays glued to the number that follows it.

Look ahead (optional): the word “group”

When a set with one operation is closed, associative, has an identity, and every element has an opposite (inverse), mathematicians call it a group. So $(\mathbb{Z},+)$ is a group; if it is also commutative it is called an abelian group. $(\mathbb{Z}^+,+)$ is not: it has no identity and no opposites, which is exactly why we built $\mathbb{Z}$. And $(\mathbb{Z},\times)$ is not a group (2 has no integer inverse), which foreshadows fractions. You do not need to memorise the word now; the four rules above are what we use.

Step 4: Smart Math Thinking: Using Commutativity & Associativity

Competition problems often look impossible, until you re-order and re-group the numbers so that big calculations collapse into tiny ones. You have the two key tools: commutativity (re-order) and associativity (re-group), with signs glued to their numbers.

A

Worked example A: re-order, then re-group

What is the value of $(2+4+6+\cdots+198+200) - (1+3+5+\cdots+197+199)$?

Adding all of it up would take forever. First try a small copy of the problem. Choose how many pairs: 4

Scale up: the evens go up to $200$, so there are $100$ pairs, and each pair is $1$. The answer is $\mathbf{100}$.

B

Worked example B: write it twice (forwards and backwards)

Determine the exact value of $1+3+5+7+\cdots+199$.

Commutativity lets us write the same sum backwards. Add the two rows column by column. Number of terms: 6

Scale up: $1,3,\ldots,199$ has $100$ terms and each column adds to $200$. Two copies give $100 \times 200 = 20\,000$, so one copy is $\mathbf{10\,000}$.

Your toolkit

  • Pair up numbers that make a tidy total (like $2-1$, or a pair making $100$).
  • Write it twice (forwards and backwards) when numbers go up by equal steps. Then every column has the same total.
  • Test a small version first and look for the pattern.
  • Count carefully: how many terms? how many pairs?
