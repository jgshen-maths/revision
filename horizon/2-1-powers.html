Step 1: Squares, Cubes and Roots

In Chapter 1 you built $\mathbb{Z}$ and learned to split numbers into primes. Chapter 2 extends our number system to the rational numbers. Before fractions arrive, we sharpen the tools that every later chapter leans on: powers, roots and the correct order of calculation. We start with the most famous powers of all: squares and cubes.

1

Square numbers and cube numbers are sets

Use the set language of Chapters 1 and 2. Let $\mathbb{Z}^+=\{1,2,3,\ldots\}$. The set of square numbers and the set of cube numbers are

$$Sq=\{n^2:\ n\in\mathbb{Z}^+\}=\{1,4,9,16,25,\ldots\},\qquad Cb=\{n^3:\ n\in\mathbb{Z}^+\}=\{1,8,27,64,125,\ldots\}.$$

  • $49\in Sq$ because $49=7^2$, but $50\notin Sq$ (it lies between $7^2=49$ and $8^2=64$).
  • $n(Sq\cap\{1,2,\ldots,100\})=10$, the squares $1^2,2^2,\ldots,10^2$.
  • $Sq\cap Cb=\{1,64,729,\ldots\}$: numbers that are both. $64=8^2=4^3$. You will see in Step 1 of Tab 5 why these are exactly the sixth powers $n^6$.

The root undoes the power. $\sqrt{x}$ (the square root) means the non-negative number whose square is $x$, so $\sqrt{49}=7$ (the other number whose square is $49$ is $-7$, but $\sqrt{\ }$ always gives the non-negative one). $\sqrt[3]{x}$ (the cube root) is the number whose cube is $x$, and it can be negative: $\sqrt[3]{-27}=-3$.

Theorem 1: the sum of the first $n$ odd numbers is $n^2$

$1+3+5+\cdots+(2n-1)=n^2$ for every positive integer $n$.

What this theorem says, with examples

Example 1: small cases

$1=1^2$. $\;1+3=4=2^2$. $\;1+3+5=9=3^2$. $\;1+3+5+7=16=4^2$. Each new odd number completes a bigger square.

Example 2: a quick sum

Add the first $12$ odd numbers. There is no need to add them one by one: the answer is $12^2=144$. The last number added is $2\times12-1=23$.

Example 3: working backwards

If $1+3+5+\cdots+L=441$, then $441=21^2$, so $21$ odd numbers were added and the last one is $L=2\times21-1=41$.

Show the proof (optional reading for the curious)
Picture. Take an $n\times n$ square of dots. Remove the top row and the right column together: they form an L-shape (a gnomon) of $2n-1$ dots, because the corner dot is shared. What is left is an $(n-1)\times(n-1)$ square.
Repeat. Remove an L of $2n-3$ dots, then $2n-5$, and so on down to a single dot. So $n^2=(2n-1)+(2n-3)+\cdots+3+1$. $\blacksquare$
Technique 1: decide whether a number is a perfect square (or cube)

Two quick tests, from fastest to most certain.

  1. Last-digit test (can only say NO). A square ends in $0,1,4,5,6$ or $9$. It never ends in $2,3,7$ or $8$. (Check: $1^2,2^2,\ldots,9^2$ end in $1,4,9,6,5,6,9,4,1$.)
  2. Prime-factor test (decides it). Write the number as a product of primes. It is a perfect square exactly when every index is even, and a perfect cube exactly when every index is a multiple of $3$.

Example 1: Is $3528$ a perfect square? It ends in $8$, so no, immediately.

Example 2: Is $7056$ a perfect square? It ends in $6$, so it might be. Factorise: $7056=2^4\times3^2\times7^2$. All indices ($4,2,2$) are even, so yes, and $\sqrt{7056}=2^2\times3\times7=84$ (halve each index).

Example 3: $1728=2^6\times3^3$. Indices $6$ and $3$ are both multiples of $3$, so $1728$ is a perfect cube: $\sqrt[3]{1728}=2^2\times3=12$ (divide each index by $3$).

Technique 2: the smallest multiplier that makes a perfect square or cube

Factorise. For a square, look at every prime whose index is odd and multiply by one more copy of it. For a cube, top each index up to the next multiple of $3$.

Example 1: Smallest $n$ so that $50n$ is a perfect square. $50=2\times5^2$. The index of $2$ is odd, so $n=2$, giving $100=10^2$.

Example 2: Smallest $n$ so that $54n$ is a perfect cube. $54=2\times3^3$. The index of $2$ is $1$, which must become $3$, so we need $2^2$ more: $n=4$. Check: $54\times4=216=6^3$.

The Locker Puzzle: why are square numbers special?

A real puzzle from a school corridor

A corridor has $100$ lockers, all closed. Student $1$ walks down and opens every locker. Student $2$ walks down and flips every second locker (open becomes closed, closed becomes open). Student $3$ flips every third locker, student $4$ every fourth, and so on, until student $100$ flips just locker $100$.

Which lockers are open at the end? Run the experiment below and look at the pattern before reading on.

Orange = open at the end. Click any locker to see how many times it was flipped (one flip for each factor of its number).

The clue. Locker $k$ is flipped by student $d$ exactly when $d$ is a factor of $k$. It starts closed, so it ends open only if it was flipped an odd number of times. So the open lockers are those whose number has an odd number of factors. And that is exactly the square numbers.

Theorem 2: a positive integer has an odd number of factors if and only if it is a perfect square
What this theorem says, with examples

Example 1: a square, an odd count

The factors of $36$ are $1,2,3,4,6,9,12,18,36$. That is $9$ factors, an odd number. Pair them: $(1,36),(2,18),(3,12),(4,9)$ and the lonely $6$, which is paired with itself because $6\times6=36$.

Example 2: a non-square, an even count

The factors of $20$ are $1,2,4,5,10,20$: $6$ factors, all in pairs $(1,20),(2,10),(4,5)$. There is no lonely factor because $20$ is not a square.

Example 3: using the factor-counting box from 1.2

$144=2^4\times3^2$ has $(4+1)(2+1)=15$ factors: odd, and $144=12^2$. In general, the number of factors is a product of $(\text{index}+1)$ terms, which is odd only when every index is even.

Show the proof (optional reading for the curious)
Pairing. If $d$ is a factor of $n$, then so is $n\div d$. This pairs each factor $d$ with a partner $n\div d$, and $d\times(n\div d)=n$.
When is a factor its own partner? Exactly when $d=n\div d$, that is $d^2=n$. This can only happen if $n$ is a perfect square, and then there is exactly one such $d$, namely $\sqrt n$.
Count. If $n$ is not a perfect square, all factors come in pairs of two different numbers, so the count is even. If $n$ is a perfect square, the pairs use an even number of factors and $\sqrt n$ is left over, so the count is odd. $\blacksquare$

Answer to the puzzle: the open lockers are $1,4,9,16,25,36,49,64,81,100$. Ten lockers, the squares up to $100$.

Step 2: Index Notation and the Index Laws

Squares and cubes are only the first two members of a huge family: $2^{10}$, $5^{130}$, $10^{-3}$. This tab explains where powers come from, why the index laws work (by simply counting factors), and why $2^0$ has to equal $1$.

1

Where powers come from: the paper-folding story

Scene 1: fold a sheet of paper in half, again and again

A sheet of paper is about $0.1$ mm thick. Fold it in half: $2$ layers, $0.2$ mm. Fold again: $4$ layers. Fold again: $8$ layers. Every fold doubles the number of layers.

Thickness0.2 mm0.4 mm0.8 mm1.6 mm3.2 mmabout 10 cmabout 105 m

After $10$ folds the stack is as thick as a hand. After $20$ it is as tall as a 30-storey building. After $42$ folds it would be about $440\,000$ km tall, further than the Moon! (This is a thought experiment: nobody can fold a sheet more than about $7$ or $8$ times.)

After $n$ folds there are $2\times2\times\cdots\times2$ ($n$ twos) layers. Writing that out for $n=42$ is painful. So we invented a short way to write it.

Index notation. $a^n$ means $a$ multiplied by itself $n$ times:

$$a^n=\underbrace{a\times a\times\cdots\times a}_{n\text{ factors}}.$$

$a$ is the base and $n$ is the index (or exponent). So the paper stack after $n$ folds has $2^n$ layers. Reading aloud: $5^3$ is “five to the power three” or “five cubed”, and $5^2$ is “five squared”. A power is a bundle of repeated multiplication, just as $3\times2$ is a bundle of repeated addition.

The index laws: just count the factors

Theorem 3: the index laws (positive whole-number indices $m$ and $n$, non-zero bases $a$ and $b$)
  1. Multiply, same base: $a^m\times a^n=a^{m+n}$.
  2. Divide, same base ($m>n$): $a^m\div a^n=a^{m-n}$.
  3. Power of a power: $(a^m)^n=a^{mn}$.
  4. Power of a product: $(ab)^n=a^n\,b^n$, and likewise $\left(\dfrac ab\right)^n=\dfrac{a^n}{b^n}$.
What these laws say, with examples

Law 1: $2^3\times2^4$

$(2\times2\times2)\times(2\times2\times2\times2)$ is seven twos in a row, so it is $2^7=128$. Check with numbers: $8\times16=128$. ✓ The indices add because we are counting factors.

Law 2: $5^6\div5^4$

$\dfrac{5\times5\times5\times5\times5\times5}{5\times5\times5\times5}$: four fives cancel, leaving $5^2=25$. Check: $15625\div625=25$. ✓

Law 3: $(3^2)^3$

$(3\times3)\times(3\times3)\times(3\times3)$: three groups of two threes, so $3^6=729$. Check: $9^3=729$. ✓ The indices multiply because we have $n$ groups of $m$ factors.

Law 4: $(2\times5)^3$ and $6^4$

$(2\times5)^3=2^3\times5^3=8\times125=1000=10^3$. ✓ And $6^4=(2\times3)^4=2^4\times3^4=16\times81=1296$. Splitting a base into prime factors splits the power too.

What the laws do not say

$2^3\times3^2$ cannot be combined: the bases differ, so it is just $8\times9=72$. And $2^3+2^4$ is not $2^7$: it is $8+16=24$. The laws are about multiplying and dividing, never adding. Likewise $(3+4)^2=49$ but $3^2+4^2=25$.

Show the proof (optional reading for the curious)
Law 1. $a^m$ is $m$ factors of $a$ and $a^n$ is $n$ factors of $a$. Multiplying them puts $m+n$ factors of $a$ in a row, which is $a^{m+n}$.
Law 2. $a^m\div a^n$ is a fraction with $m$ factors of $a$ on top and $n$ on the bottom. Cancel $n$ pairs: $m-n$ factors remain on top.
Law 3. $(a^m)^n$ is $n$ copies of $a^m$ multiplied together. By Law 1 the indices add $n$ times: $m+m+\cdots+m=mn$.
Law 4. $(ab)^n=(ab)(ab)\cdots(ab)$. Multiplication can be reordered (commutativity and associativity from 1.1 and 2.2), so collect the $a$'s and the $b$'s: $a^n b^n$. $\blacksquare$

Three classic traps

  • $2^3\times2^4$ is not $4^7$. Only the indices add. The base stays $2$.
  • $-3^2$ means $-(3^2)=-9$, but $(-3)^2=9$. The power belongs to what is directly in front of it.
  • $3\times4^2$ is $3\times16=48$, not $12^2=144$.
Technique 3: simplify a numerical expression with the index laws

Keep the same base. Add indices when multiplying, subtract when dividing, multiply when raising a power to a power. Only then evaluate.

Example 1: $\dfrac{2^7\times2^2}{2^4}=2^{7+2-4}=2^5=32$.

Example 2: $(5^2)^3\div5^4=5^6\div5^4=5^2=25$.

Example 3: $(-2)^3\times(-2)^2=(-2)^5=-32$ (the base is $-2$, and five negative factors give a negative result).

Technique 4: write everything as a power of the same prime (common base)

Many different-looking numbers are secretly powers of one prime: $4=2^2$, $8=2^3$, $16=2^4$, $32=2^5$, $64=2^6$; $9=3^2$, $27=3^3$, $81=3^4$; $25=5^2$, $125=5^3$. Rewrite with a common base, then use the rule: if $a>1$ and $a^x=a^y$, then $x=y$ (the powers of $a$ keep growing, so they never repeat).

Example 1: Solve $4^x=32$. Write $4=2^2$ and $32=2^5$: $2^{2x}=2^5$, so $2x=5$ and $x=2.5$.

Example 2: To what power must we raise $9^2$ to get $27^4$? $9^2=(3^2)^2=3^4$ and $27^4=(3^3)^4=3^{12}$. Then $(3^4)^x=3^{4x}=3^{12}$, so $x=3$.

Example 3: Which power of $8$ equals $32^{6}$? $32^6=(2^5)^6=2^{30}$ and $8^x=2^{3x}$, so $3x=30$ and $x=10$.

Technique 5: factor out the smallest power

Index laws do not work on sums, but you can factor a sum of powers: take out the smallest power, using Law 1 backwards.

Example 1: $2^{10}+2^9=2^9\times(2+1)=3\times2^9$.

Example 2: $\dfrac{3^{20}-3^{18}}{3^{18}}=\dfrac{3^{18}(3^2-1)}{3^{18}}=3^2-1=8$.

Example 3: $2^{101}-2^{100}=2^{100}(2-1)=2^{100}$: one doubling step leaves exactly what it started with.

What must $2^0$ be? Powers that keep going down

Scene 2: keep halving

Read the powers of $2$ from the top, each time one index lower:

$2^4$$2^3$$2^2$$2^1$$2^0$$2^{-1}$$2^{-2}$$2^{-3}$
16842????

Every step to the right divides by $2$: $16,8,4,2,\ldots$ The pattern says $2^0=1$, then $2^{-1}=\tfrac12$, $2^{-2}=\tfrac14$, $2^{-3}=\tfrac18$. The fraction numbers you will study next in 2.2 appear naturally here.

Is that just a nice pattern, or is it forced on us? Open the proof in Theorem 4.
Theorem 4: zero and negative indices (for $a\ne0$)

If the index laws are to keep working for all whole-number indices, then we must have $$a^0=1\qquad\text{and}\qquad a^{-n}=\frac1{a^n}.$$

What this theorem says, with examples

Example 1: zero index

$7^0=1$, $\;(-5)^0=1$, $\;2026^0=1$. Every non-zero number to the power zero is $1$.

Example 2: negative index means reciprocal

$10^{-3}=\dfrac1{10^3}=\dfrac1{1000}=0.001$. $\;5^{-2}=\dfrac1{25}=0.04$. $\;2^{-4}=\dfrac1{16}$. The minus sign in the index does not make the number negative: it flips to a reciprocal.

Example 3: the laws still work

$2^3\times2^{-5}=2^{3-5}=2^{-2}=\dfrac14$. Check by hand: $8\times\dfrac1{32}=\dfrac8{32}=\dfrac14$. ✓ And $\dfrac{5^2}{5^6}=5^{2-6}=5^{-4}=\dfrac1{625}$.

Show the proof (why there is no other choice)
Zero index. Law 1 says $a^m\times a^n=a^{m+n}$. If this is to hold with $m=0$, then $a^0\times a^n=a^{0+n}=a^n$. Dividing both sides by $a^n$ (which is not zero) gives $a^0=1$. (Another view: Law 2 gives $a^n\div a^n=a^{n-n}=a^0$, and anything divided by itself is $1$.)
Negative index. With $m=-n$: $a^{-n}\times a^n=a^{-n+n}=a^0=1$. So $a^{-n}$ is the number that multiplies $a^n$ to give $1$, which is the reciprocal $\dfrac1{a^n}$. $\blacksquare$
Note. This is not a theorem found by calculation. It is a definition that mathematicians chose, because it is the only one that keeps the old laws true. Mathematics often grows this way.

Step 3: The Order of Calculation

What is $2+3\times4$? Two careful people can get two different answers. This tab explains why we all agree on one, how brackets let us override the agreement, and how to make a calculator obey us.

1

Why do we need an agreed order?

Scene 1: two friends, one text message

Ana texts Ben: 2+3×4. “What is it?” Ben works left to right: $2+3=5$, then $5\times4=20$. Ana says $14$. They both used a calculator, and the calculators disagreed with each other!

Think of a snack bar: a drink costs $2$ points and chips cost $4$ points a pack. You buy a drink and $3$ packs of chips. The total is obviously $2+(3\times4)=2+12=14$ points. The $3\times4$ is one bundle (three packs), and the drink is added on top.

The order of calculation is not a theorem we proved. It is a convention, like driving on the left in New Zealand: everyone agrees so that a message means the same to every reader. But there is a sensible reason behind it, as you will see.

The order of calculation (BIDMAS)

  1. Brackets first, working from the innermost pair outwards.
  2. Indices (powers and roots).
  3. Division and Multiplication, equal rank: work left to right.
  4. Addition and Subtraction, equal rank: work left to right.

Why this order? Each level is a bundle of the level below. A power is repeated multiplication ($4^2=4\times4$), and multiplication is repeated addition ($3\times4=4+4+4$). Bundles are done before they are combined with a plain neighbour. Division and multiplication share a rank because division is multiplication by a reciprocal; subtraction and addition share a rank because subtraction is addition of the opposite (the idea from 1.1).

Other countries say PEMDAS or BODMAS. The rule is the same. Careful: “D before M” in the word does not mean division beats multiplication. $48\div6\times2=8\times2=16$, not $48\div12=4$.

Try it: the Order Stepper (type any expression and watch each step, the underlined part is done next)

Type * for ×, / for ÷, ^ for a power, and use brackets. Try these:

Technique 6: calculate in the right order, and write one step per line

Underline the next operation, do only that, and copy everything else unchanged. Never do two levels in one line when you are learning.

Example 1: $6+4\times3^2$. Index first: $6+4\times9$. Then multiply: $6+36=42$.

Example 2: $(6+4)\times3^2$. Brackets first: $10\times3^2$. Index: $10\times9=90$. The brackets changed the answer from $42$ to $90$.

Example 3 (nested brackets): $3\times[2+(8-5)^2]-4$. Innermost bracket: $8-5=3$. Then $3\times[2+3^2]-4=3\times[2+9]-4=3\times11-4=33-4=29$.

Technique 7: fraction bars and root signs are hidden brackets

A fraction bar groups the whole top and the whole bottom, and a root sign groups everything under it. Calculate the top, the bottom, or the radicand first.

Example 1: $\dfrac{3^2+4^2}{10-5}=\dfrac{9+16}{5}=\dfrac{25}{5}=5$.

Example 2: $\sqrt{3^2+4^2}=\sqrt{25}=5$. This is not $3+4=7$. (Roots do not split over addition.)

Example 3 (typing it): to calculate $\dfrac{12+8}{4}$ on a calculator, type (12+8)÷4 and get $5$. Typing 12+8÷4 gives $14$, because the calculator divides first. The brackets you see in the fraction must be typed.

Technique 8: negatives and powers, and towers of powers

The power belongs to what is directly in front of it. For a tower $a^{b^c}$, the convention is to work from the top down: $a^{(b^c)}$.

Example 1: $-3^2=-(3\times3)=-9$, but $(-3)^2=(-3)\times(-3)=9$. So $-3^2+(-3)^2=-9+9=0$.

Example 2: $2^{3^2}=2^9=512$, but $(2^3)^2=8^2=64$. Two quite different numbers from the same digits! By Law 3, $(2^3)^2=2^6$.

Technique 9: look at the structure before you calculate (grouping)

Addition and subtraction chains can be grouped (associativity, 2.1) into pairs that behave simply. Spot the pattern with a short case first.

Example 1: $1-2+3-4+5-6=(1-2)+(3-4)+(5-6)=-1-1-1=-3$. Three pairs, each worth $-1$.

Example 2: $1-2+3-4+\cdots+9-10$. There are $5$ pairs, each $-1$, so the answer is $-5$.

Example 3: $2+4+6+\cdots+20$. Pair first with last: $2+20=22$, $4+18=22,\ldots$ There are $5$ such pairs: $5\times22=110$.

Technique 10: use the calculator wisely, and check it by estimation

A calculator obeys the order of calculation exactly, and does only what you type. So: (1) type brackets wherever you see grouping; (2) key in negatives with the “(-)” key, inside brackets when squared: (-3)^2; (3) estimate first by rounding each number, so a typing slip shows up at once.

Example: $\dfrac{48.7+151.6}{3.9^2-5.1}$. Estimate: $\dfrac{50+150}{16-5}=\dfrac{200}{11}\approx18$. Calculator: type (48.7+151.6)÷(3.9^2-5.1) and get $\approx19.8$. The two agree roughly, so no slip. If the calculator had shown about $53.6$ (what you get from typing the line without any brackets), you would know that brackets were missing.

Step 4: How Big Is Big? Estimation, Digits and Last Digits

Powers grow terrifyingly fast. A calculator shows only “E+” for the big ones, so we need skills a calculator does not have: to estimate the size of a number, to count its digits, and to find its last digit with a little help from the clock arithmetic of 1.3.

1

Real life first: how long to guess a password?

Scene 1: a PIN versus a word

An online game protects your account with an 8-digit PIN. A thief’s program can try $1\,000\,000$ guesses every second. A friend uses an 8-letter password instead (lower-case letters only).

  • Each digit has $10$ choices, so there are $10\times10\times\cdots\times10=10^8=100\,000\,000$ PINs. At $10^6$ guesses a second, the thief needs at most $10^8\div10^6=100$ seconds, under two minutes.
  • Each letter has $26$ choices, so there are $26^8$ passwords. Estimate: $26^8\approx(2.6\times10)^8$, and $2.6^8\approx2.1\times10^3$, so $26^8\approx2\times10^{11}$. That takes $2\times10^{5}$ seconds, about 2.4 days.
The same number of characters, but about two thousand times more work for the thief. Powers show why: the base ($26$ against $10$) matters as much as the length. To compare such huge numbers we estimate with powers of $10$, which is the skill of this tab.
2

Estimating with squares, cubes and powers of ten

Technique 11: sandwich a root between two perfect powers

To estimate $\sqrt N$, find the two perfect squares that $N$ lies between. To estimate $\sqrt[3]{N}$, use the two perfect cubes around it. Then use how close $N$ is to each to refine your guess.

Example 1: $\sqrt{200}$. $14^2=196$ and $15^2=225$, so $14\lt\sqrt{200}\lt15$. Since $200$ is only $4$ above $196$ but $25$ below $225$, the root is just above $14$: about $14.1$. (A calculator says $14.142\ldots$)

Example 2: $\sqrt[3]{300}$. $6^3=216$ and $7^3=343$, so the root is between $6$ and $7$, closer to $7$ (as $300$ is nearer $343$): about $6.7$.

Two facts that make big numbers manageable.

  1. $2^{10}=1024\approx10^3$. So $2^{20}\approx10^6$, $2^{30}\approx10^9$, $2^{40}\approx10^{12}$. (Each factor $1024$ is $2.4\%$ above $1000$, so the approximation drifts slowly upwards.)
  2. A positive integer $N$ has exactly $d$ digits when $10^{d-1}\le N\lt10^d$. For example $10^{12}$ is the smallest $13$-digit number.

Try it: the Digit Counter (exact digits, first digits and last digit)

Theorem 5: if $2^n$ has $k$ digits, then $5^n$ has $n-k+1$ digits

Because $2^n\times5^n=10^n$, the digit counts of $2^n$ and $5^n$ are linked.

What this theorem says, with examples

Example 1: a small check

$2^{10}=1024$ has $k=4$ digits. So $5^{10}$ has $10-4+1=7$ digits. Indeed $5^{10}=9\,765\,625$, seven digits. ✓

Example 2: $5^{20}$

$2^{20}=1\,048\,576$ has $7$ digits, so $5^{20}$ has $20-7+1=14$ digits ($5^{20}=95\,367\,431\,640\,625$). ✓

Example 3: a number too big for a calculator

$5^{130}$: first count the digits of $2^{130}$. Since $2^{130}=(2^{10})^{13}=1024^{13}$ and $1000^{13}=10^{39}\le1024^{13}\lt(1.1\times1000)^{13}\lt10^{40}$ (because $1.1^{13}\lt10$), the number $2^{130}$ has $40$ digits. So $5^{130}$ has $130-40+1=\mathbf{91}$ digits.

Show the proof (optional reading for the curious)
Setup. Suppose $2^n$ has $k$ digits: $10^{k-1}\le2^n\lt10^k$ (the number is never equal to $10^k$ because $2^n$ has no factor $5$).
Divide. $5^n=\dfrac{10^n}{2^n}$. Dividing $10^n$ by a number in $[10^{k-1},10^k)$ gives a result in $(10^{n-k},10^{n-k+1}]$. And $5^n\ne10^{n-k+1}$ since $5^n$ is odd, so $10^{n-k}\lt5^n\lt10^{n-k+1}$.
Conclude. A number at least $10^{n-k}$ (strictly above) but below $10^{n-k+1}$ has exactly $n-k+1$ digits. $\blacksquare$
Technique 12: pair every 2 with a 5 to make a power of ten

A product of powers of $2$ and $5$ is easy to read when you pair them off: $2^a\times5^a=10^a$. The leftover factor tells you the leading digits, and $10^a$ adds $a$ zeros.

Example 1: $2^{12}\times5^{9}=2^3\times(2^9\times5^9)=8\times10^9$. That is an $8$ followed by $9$ zeros: $10$ digits.

Example 2: $4^{10}\times25^{8}=2^{20}\times5^{16}=2^4\times10^{16}=16\times10^{16}$: the digits $16$ then $16$ zeros, so $18$ digits. (Rewrite $4=2^2$ and $25=5^2$ first: that is common-base thinking from Tab 2.)

Example 3: $8^{5}\times5^{15}=2^{15}\times5^{15}=10^{15}$, which has $16$ digits.

Technique 13: count the digits of a power of 5 (or any hard power)

Use Theorem 5: count the digits of $2^n$ by sandwiching with $2^{10}\approx10^3$, then subtract. For a base like $5$, write $5^n=\dfrac{10^n}{2^n}$.

Example: How many digits has $5^{40}$? $2^{40}=1024^4\approx1.1\times10^{12}$, which has $13$ digits. So $5^{40}$ has $40-13+1=28$ digits. (Exactly: $5^{40}=9.09\ldots\times10^{27}$.)

The last digit: powers on the clock

In 1.3 you learned that the last digit of $N$ is $N\bmod10$, and that powers cycle on the clock. Let us use that. The last digit of a product depends only on the last digits of its factors. Look at the last digits of $a^1,a^2,a^3,\ldots$:

Try it: the Last-Digit Cycle Finder

Technique 14: the last digit of $a^n$ (find the cycle, then reduce the index)
  1. Keep only the last digit of the base.
  2. List its powers until the last digit repeats. Count the cycle length $L$.
  3. Divide the index by $L$. The remainder says which term of the cycle to read; a remainder of $0$ means the last term of the cycle.

Example 1: Last digit of $7^{2026}$. Cycle $7,9,3,1$ (length $4$). $2026=4\times506+2$, remainder $2$, so the second term: $9$.

Example 2: Last digit of $2^{100}$. Cycle $2,4,8,6$. $100=4\times25+0$, remainder $0$, so the last term: $6$.

Example 3: Last digit of $13^{13}$. Only the last digit of the base matters: $3^{13}$. Cycle $3,9,7,1$. $13=4\times3+1$, so the first term: $3$.

Example 4 (a sum): Last digit of $2^{30}+3^{30}$. $2^{30}$: $30=4\times7+2$, second term $4$. $3^{30}$: second term $9$. $4+9=13$, so the last digit is $3$.

Step 5: Smart Thinking with Powers (Competition Techniques)

Competition problems rarely ask for a long calculation. They ask whether you can see a structure: compare two giants without computing them, trap a number between two easy bounds, or add a long list in one move. Four techniques cover almost everything in this tab.

1

Comparing giants: bring them to a common exponent

The idea. Two powers with different bases and different indices are hard to compare. But if the indices share a common factor $g$, we can rewrite both as something to the power $g$ using Law 3 backwards, $a^{gk}=(a^k)^g$. Then the bigger base wins, because for $g>0$ and positive bases, a larger base gives a larger power.

Same trick for the sets of 2.1: $Sq\cap Cb$ is the set of numbers that are both squares and cubes. In prime factors, every index must be even and a multiple of $3$, so a multiple of $6$: they are exactly the sixth powers $1,64,729,4096,\ldots$

Try it: the Giant Comparer

to the power versus to the power
Technique 15: compare or order large powers
  1. Find the HCF $g$ of the indices.
  2. Rewrite each power as (base to the power $\text{index}\div g$) to the power $g$.
  3. Compute the small bases $a^{m/g}$ and compare them. The order of the small numbers is the order of the giants.
  4. If there is no useful common factor, squeeze with an easy intermediate number (see Example 3).

Example 1: Which is bigger, $2^{300}$ or $3^{200}$? HCF$(300,200)=100$. $2^{300}=(2^3)^{100}=8^{100}$ and $3^{200}=(3^2)^{100}=9^{100}$. Since $8\lt9$, $3^{200}$ is bigger.

Example 2: Order $2^{60},\ 3^{40},\ 5^{20}$ from smallest to largest. HCF of $60,40,20$ is $20$: $2^{60}=8^{20}$, $3^{40}=9^{20}$, $5^{20}=5^{20}$. So $5^{20}\lt2^{60}\lt3^{40}$.

Example 3 (squeeze with a power of ten): Compare $2^{50}$ and $10^{15}$. The indices $50$ and $15$ have HCF $5$: $2^{50}=(2^{10})^5=1024^5$ and $10^{15}=(10^3)^5=1000^5$. Since $1024>1000$, $2^{50}>10^{15}$. This is the fact $2^{10}\approx10^3$ from Tab 4 at work.

2

Squeezing with Bernoulli: how fast does $(1+x)^n$ grow?

Scene 1: a savings account

A savings account pays $1\%$ interest a year, added to the balance each year. After $n$ years your money is multiplied by $1.01\times1.01\times\cdots\times1.01=1.01^n$. A natural question: how long until the money has at least doubled? Could $100$ years do it? You cannot compute $1.01^{100}$ in your head, but you can bound it, and that is enough.

Key insight: when you expand a product of many $(1+x)$ factors, the answer is at least $1+nx$, because there are $n$ ways to pick one $x$ and all the other parts are positive.
Theorem 6 (Bernoulli’s inequality): for $x\ge0$ and a positive integer $n$, $(1+x)^n\ge1+nx$
What this theorem says, with applications

Application 1: doubling money

$1.01^{100}\ge1+100\times0.01=2$. So after $100$ years at $1\%$, money has at least doubled. (It really becomes about $2.7$ times as much.)

Application 2: a competition result, $1.01^{300}>4$

Split the index with Law 3: $1.01^{300}=(1.01^{100})^3\ge2^3=8>4$. We did not compute anything big, yet the inequality is proved (the true value is about $19.8$).

Application 3: splitting gives a better bound

Direct use on $1.001^{2000}$ gives only $1+2000\times0.001=3$. Split first: $1.001^{1000}\ge1+1=2$, so $1.001^{2000}=(1.001^{1000})^2\ge4$. A sharper bound, from one extra Law 3 step.

Application 4: a quick lower bound for a power of $1.1$

$1.1^{10}\ge1+10\times0.1=2$. So at $10\%$ a year, money doubles in at most $10$ years (in fact $7.3$ years).

Show the proof (optional reading for the curious)
Induction idea. For $n=1$: $(1+x)^1=1+x\ge1+1\cdot x$. ✓
Step. Assume $(1+x)^n\ge1+nx$. Multiply both sides by $1+x$ (positive): $(1+x)^{n+1}\ge(1+nx)(1+x)=1+(n+1)x+nx^2\ge1+(n+1)x$, since $nx^2\ge0$. So the statement for $n$ gives the statement for $n+1$, and so it holds for every $n$. $\blacksquare$
Intuition. Expanding $(1+x)(1+x)\cdots(1+x)$ gives $1+nx$ plus many more non-negative terms such as $x^2$.
Technique 16: prove a big power exceeds a target (split, bound, cube)
  1. Write the base as $1+x$ with $x$ small and positive.
  2. Split the index so that one piece makes $nx$ about $1$: this gives a power that is at least $2$.
  3. Raise that bound to the remaining power using Law 3.

Example: Show $1.02^{150}>8$. $1.02^{50}\ge1+50\times0.02=2$. Then $1.02^{150}=(1.02^{50})^3\ge2^3=8$. (In fact it is greater than $8$ strictly, because Bernoulli drops positive terms.)

3

Adding a long list of powers in one move

Scene 2: the paper-folding bill

A magazine offers you a deal: on day $1$ it pays you $1$ point, on day $2$ it pays $2$ points, on day $3$ it pays $4$, and the payment doubles every day for $10$ days. How many points altogether? Adding $1+2+4+8+\cdots+512$ is slow. There is a shortcut that works for any number of days.

Theorem 7: $1+2+4+\cdots+2^{n}=2^{n+1}-1$
What this theorem says, with examples

Example 1: the 10-day bill

$1+2+4+\cdots+2^9=2^{10}-1=1023$ points.

Example 2: a binary fact

$1+2+4+8+16=31=2^5-1$. Any number up to $31$ can be built by choosing from the pieces $1,2,4,8,16$: that is how binary numbers work.

Example 3: starting later

$2+4+8+\cdots+2^{10}=(1+2+4+\cdots+2^{10})-1=(2^{11}-1)-1=2^{11}-2=2046$.

Example 4: the same trick with ratio $3$

Let $T=1+3+9+27+81$. Multiply by $3$: $3T=3+9+27+81+243$. Subtract: $3T-T=243-1$, so $2T=242$ and $T=121$.

Show the proof (optional reading for the curious)
The doubling trick. Let $S=1+2+4+\cdots+2^n$. Then $2S=2+4+8+\cdots+2^{n+1}$.
Subtract. $2S-S$: every term cancels except the last term of $2S$ and the first term of $S$. So $S=2^{n+1}-1$. $\blacksquare$
Technique 17: sum a doubling (or tripling) list

Name the sum, multiply it by the ratio, subtract, and read the answer off the two ends. Check by testing the first few terms.

Example: $1+2+4+\cdots+2^{12}=2^{13}-1=8191$. Check the pattern on a short version: $1+2+4=7=2^3-1$. ✓

4

Squares in disguise: the difference of two squares

Theorem 8: $a^2-b^2=(a-b)(a+b)$
What this theorem says, with examples

Example 1: a mental calculation

$101^2-99^2=(101-99)(101+99)=2\times200=400$. Check: $10201-9801=400$. ✓

Example 2: near a round number

$999^2-1=(999-1)(999+1)=998\times1000=998\,000$.

Example 3: with powers

$(2^{10}+1)(2^{10}-1)=(2^{10})^2-1=2^{20}-1$. This is the law in reverse: a product of $(a+b)(a-b)$ collapses to a difference of squares.

Show the proof (optional reading for the curious)
Area picture. Take a square of side $a$ and cut out a corner square of side $b$. What is left is an L-shape of area $a^2-b^2$. Cut the L into two rectangles and rearrange them: they form one rectangle with sides $a-b$ and $a+b$.
Expanding. $(a-b)(a+b)=a(a+b)-b(a+b)=a^2+ab-ab-b^2=a^2-b^2$. $\blacksquare$
Technique 18: spot $a^2-b^2$ in a calculation

If you see two squares being subtracted, or a pair like $(N-k)(N+k)$, switch to the other form. It turns two big squares into one easy product.

Example: $51^2-49^2=(51-49)(51+49)=2\times100=200$. And $(2^{50}+1)(2^{50}-1)+1=2^{100}-1+1=2^{100}$.
