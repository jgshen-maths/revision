Step 1: What Is a Set?

Before numbers, before equations, mathematics starts with something simpler: putting things together into a collection. That collection is called a set, and its language will follow you through every chapter of this course.

1

A set is a well-defined collection

A set is a collection of distinct objects, called its elements. We write the elements inside curly brackets: $V=\{\text{carrot},\ \text{broccoli},\ \text{spinach}\}$.

  • Well-defined: for any object you must be able to say yes, it is in or no, it is not. “The vowels” is a set. “Nice songs” is not, because people disagree.
  • Order does not matter: $\{1,2,3\}=\{3,1,2\}$.
  • Repeats do not count: $\{1,1,2,3\}=\{1,2,3\}$. Each element is listed once.
2

Belonging: $\in$ and $\notin$

Technique 1: read the symbols aloud

$x\in A$ reads “$x$ is an element of $A$”. $x\notin A$ reads “$x$ is not an element of $A$”.

Example. $V=\{\text{carrot},\ \text{broccoli},\ \text{spinach}\}$. Then $\text{spinach}\in V$ and $\text{apple}\notin V$.

3

Two ways to describe a set

Technique 2: list it, or give the rule

Roster form lists the elements: $\{\text{January},\ \text{June},\ \text{July}\}$. Set-builder form gives the rule: $\{x : x \text{ is a month starting with J}\}$, read “the set of all $x$ such that $x$ is a month starting with J”.

Example. $L=\{x : x \text{ is a letter of the word BANANA}\}$. Go through the word and keep each letter once: $L=\{\text{B},\ \text{A},\ \text{N}\}$.

4

Counting elements: $n(A)$ and the empty set

$n(A)$ is the number of distinct elements in $A$ (its cardinality). For the set $L$ above, $n(L)=3$, not $6$.

The empty set has no elements at all. We write it $\varnothing$ or $\{\ \}$, and $n(\varnothing)=0$.

Trap. $\{0\}$ is not empty: it has one element, the number $0$. And $\{\varnothing\}$ is not empty either: it is a box containing one empty box.

Step 2: Subsets and the Power Set

Sets can sit inside other sets. The positive integers sit inside the integers; your class sits inside your school. This idea, the subset, is how mathematicians organise every family of numbers.

1

Subsets: $\subseteq$ and $\subset$

$A\subseteq B$ (“$A$ is a subset of $B$”) means every element of $A$ is also in $B$.

$A\subset B$ (“proper subset”) means $A\subseteq B$ and $A\neq B$: $B$ has at least one extra element.

  • Every set is a subset of itself: $A\subseteq A$.
  • The empty set is a subset of every set: there is nothing in $\varnothing$ that could fail the test.
Technique 1: check element by element

To test $A\subseteq B$, take each element of $A$ in turn and ask “is it in $B$?”. One “no” is enough to say $A\not\subseteq B$.

Example. $\{2,4\}\subseteq\{1,2,3,4\}$: $2$ ✔, $4$ ✔. But $\{2,5\}\not\subseteq\{1,2,3,4\}$ because $5$ is not in the bigger set.

Trap: $\in$ or $\subseteq$? An element belongs ($\in$); a set is a subset ($\subseteq$). So $2\in\{1,2\}$ but $\{2\}\subseteq\{1,2\}$. Writing $2\subseteq\{1,2\}$ is wrong: $2$ is a number, not a set.

2

How many subsets? The doubling rule

List every subset of $\{a,b\}$: $\varnothing,\ \{a\},\ \{b\},\ \{a,b\}$. That is $4$. For $\{a,b,c\}$ there are $8$. The set of all subsets of $A$ is called the power set of $A$.

Theorem 1: a set with $n$ elements has $2^n$ subsets

If $n(A)=n$, then $A$ has exactly $2^n$ subsets, and $2^n-1$ of them are proper subsets.

Example 1. Pizza toppings $\{\text{ham},\ \text{cheese},\ \text{olive}\}$: $2^3=8$ possible pizzas, from plain (the empty set) to everything.

Example 2. A set with $10$ elements has $2^{10}=1024$ subsets. Listing them by hand is hopeless; the rule counts them instantly.

Example 3. Subsets of $\{1,2,3,4,5\}$ that contain $1$: the $1$ is fixed “in”, and the other $4$ elements each choose freely, so $2^4=16$.

Show the proof (optional reading for the curious)
To build a subset, go through the $n$ elements one at a time and decide in or out. Each element gives $2$ choices, and the choices are independent, so there are $2\times2\times\cdots\times2=2^n$ ways. Different choices give different subsets, and every subset arises this way. Exactly one of them is $A$ itself, so $2^n-1$ are proper. $\blacksquare$

Step 3: The Universal Set and Set Operations

Now we combine sets. To talk about what is outside a set, we first need to agree on everything we are talking about.

1

The universal set and the complement

The universal set $\mathscr{E}$ contains every object under discussion. The complement $A'$ is everything in $\mathscr{E}$ that is not in $A$.

Example. $\mathscr{E}=\{\text{red, orange, yellow,}$ $\text{green, blue, purple}\}$ and $A=\{\text{red, yellow, blue}\}$. Then $A'=\{\text{orange, green, purple}\}$ and $n(A)+n(A')=n(\mathscr{E})=6$.

2

Intersection, union and difference

Technique 1: three operations, three words
  • $A\cap B$ (intersection, “and”): elements in both $A$ and $B$.
  • $A\cup B$ (union, “or”): elements in $A$ or $B$ or both, each listed once.
  • $A\setminus B$ (difference, “but not”): elements in $A$ that are not in $B$. It is the same as $A\cap B'$.

Example. Piano $P=\{\text{Lucas, Chloe, Oliver, Ella}\}$, violin $V=\{\text{Chloe, Ella, Jackson}\}$.

$P\cap V=\{\text{Chloe, Ella}\}$, $P\cup V=\{\text{Lucas, Chloe, Oliver,}$ $\text{Ella, Jackson}\}$, $P\setminus V=\{\text{Lucas, Oliver}\}$.

3

The Venn diagram: four regions

Two overlapping circles inside a rectangle cut $\mathscr{E}$ into four regions: only $A$, both, only $B$, and outside both. Every element lands in exactly one region. Each operation is just a choice of regions to shade.

Step 4: Counting with Venn Diagrams

Surveys ask “how many like this, how many like that?”. A Venn diagram turns a confusing list of numbers into four tidy regions. The secret is the order you fill them in.

1

Fill from the inside out

Technique 1: middle first, then the “only” parts, then outside
  1. Write the overlap (both) in the middle.
  2. Only $A$ $=n(A)-$ both. Only $B$ $=n(B)-$ both.
  3. Outside (neither) $=n(\mathscr{E})-$ (everything inside the circles).

Worked example. In a class of $30$, $18$ study Art, $16$ study Music and $4$ study neither. How many study both?

Inside the circles: $30-4=26$ students. But $18+16=34$, which is $8$ too many: those $8$ students were counted twice, once in each circle. So $8$ study both. Then only Art $=10$, only Music $=8$. Check: $10+8+8+4=30$ ✔.

2

The counting rule

Theorem 2: inclusion–exclusion for two sets

$n(A\cup B)=n(A)+n(B)-n(A\cap B)$, and $n\big((A\cup B)'\big)=n(\mathscr{E})-n(A\cup B)$.

Example 1. $50$ club members: $30$ basketball, $25$ soccer, $10$ both. $n(B\cup S)=30+25-10=45$, so $50-45=5$ play neither.

Example 2 (running it backwards). If $n(A\cup B)$ is known, the rule gives the overlap: $n(A\cap B)=n(A)+n(B)-n(A\cup B)$. That is exactly the Art and Music example: $18+16-26=8$.

Example 3 (disjoint sets). If $A$ and $B$ have no elements in common, $n(A\cap B)=0$ and the rule becomes plain adding: $n(A\cup B)=n(A)+n(B)$.

Show the proof (optional reading for the curious)
Let the three regions inside the circles hold $x$ (only $A$), $y$ (both), $z$ (only $B$). Then $n(A)=x+y$, $n(B)=y+z$ and $n(A\cup B)=x+y+z$. So $n(A)+n(B)-n(A\cap B)=(x+y)+(y+z)-y=x+y+z=n(A\cup B)$. The overlap $y$ was counted twice and is taken away once. $\blacksquare$

3

Three sets: start in the very middle

Technique 2: three circles, same idea

With three circles there are $8$ regions. Fill the centre ($A\cap B\cap C$) first. Then each “two clubs but not the third” region is the pair total minus the centre. Then the “only” regions, then outside.

Worked example. $3$ students are in Drama, Music and Art; $5$ are in Drama and Music. How many are in Drama and Music but not Art? The $5$ includes the $3$ in all three clubs, so $5-3=2$.
